# Entreno Urbión 2027 (PWA)

Web app instalable en el móvil. No necesita tienda de aplicaciones.

## Publicarla gratis en GitHub Pages
1. Crea una cuenta en github.com y un repositorio nuevo (por ejemplo `entreno`), en público.
2. Sube todos los archivos de esta carpeta (`index.html`, `sw.js`, `manifest.webmanifest`, `icons/`, `README.md`).
3. En el repositorio: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
4. Espera un minuto. Tu app estará en `https://TU-USUARIO.github.io/entreno/`.

## Instalarla en el móvil
- **Android (Chrome):** abre la dirección → menú ⋮ → **Instalar aplicación** o **Añadir a pantalla de inicio**.
- **iPhone (Safari, no Chrome):** abre la dirección → botón Compartir → **Añadir a pantalla de inicio**.

Una vez instalada, se abre como una app, sin barra del navegador, y funciona sin conexión.

## Datos
Todo se guarda en el propio teléfono. Usa **Semana → Copia de seguridad → Exportar datos** antes de cambiar de móvil o de borrar el navegador.

## intervals.icu (opcional)
En intervals.icu: **Settings → Developer → API key** (crea una clave). Tu **ID de atleta** aparece en la misma página (formato `i12345`). Introdúcelos en **Semana → intervals.icu**. Después, en **Hoy → Cargar en el rodillo**, el botón **Enviar a intervals.icu** crea el entreno en tu calendario, y de ahí pasa a Garmin si tienes la conexión activa.
